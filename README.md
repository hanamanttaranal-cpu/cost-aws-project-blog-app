Project: AWS Cost Optimization Automation

Provisioned AWS infrastructure using Terraform, including VPC, IAM, and Amazon EKS.
Deployed a Dockerized Python application on Amazon EKS using Kubernetes Deployments and Services.
Developed an AWS Lambda function to identify and stop EC2 instances tagged with AutoStop=true, reducing unnecessary compute costs.
